# 디지털 연습소

한성대 「프로그램 기획과 평가」 AI 다리 조 — 공공도서관 고령층 디지털 교육 프로그램용 연습 앱입니다.

- 카페·패스트푸드·분식 키오스크, 테이블 오더, 모바일 뱅킹, 기차 예매, 모바일 택시와 생활 서비스·사기 예방 연습 (미션 47개)
- 초보자용(기본) / 어려움 난이도에 맞춘 오늘의 연습 3가지, 출석부
- 첫 실행 시 실제 버튼을 눌러 배우는 이용 안내, 막힐 때 안내, 낯선 말 풀이, 노션에 붙여넣는 연습 기록
- 발표용 기관 선택·로그인 흐름, 기관별 로고 표시, 미션 완료 마일리지와 혜택 예시

## 주의
화면에 나오는 가게·은행·철도·택시·병원·보험 서비스 이름은 연습용으로 지어낸 것이며, 실제로 주문·결제·송금·예약·보험 청구·택시 호출·민원 발급이 일어나지 않습니다.
연습 기록과 발표용 마일리지는 사용하는 기기의 브라우저 안에만 저장됩니다.

## 기관 로그인·마일리지 발표 시연

- 로비에서 **기관 로그인** → 한성대학교·서울도서관·남산도서관·경기도서관 중 선택 → 아이디와 비밀번호를 입력합니다.
  현재는 체험용 아이디 `demo001`과 비밀번호 `demo1234`를 사용합니다. `demo`로 시작하는 체험용
  아이디만 허용하며, 입력한 비밀번호는 앱의 저장소에 기록하거나 서버로 보내지 않습니다.
  실제 학번·포털 비밀번호는 입력하지 않습니다.
- 로그인 후 선택한 기관의 로고와 이름이 로비 왼쪽 위에 표시됩니다. 하루 첫 미션 완료에 50P를
  적립하고, 7일 연속 출석 시 100P를 그 달에 한 번만 추가 적립합니다. 기존 10P 기록은 유지합니다.
- 체험 기록과 마일리지는 기관별 체험용 아이디로 분리되어 이 브라우저에 저장됩니다.
- 손님과 기기 안에서 이름만 고른 사람도 연습·출석은 이용하지만 마일리지는 적립하지 않습니다.
  시연 계정의 마일리지는 이 브라우저에만 남고, 도서관이나 학교에 전송되지 않습니다.
- 기관 포털 인증, 회원 정보 조회, 공용 마일리지 장부, 실제 혜택 교환은 연결되지 않았습니다.
  시연용 로그인과 점수는 사용자 브라우저에서 바꿀 수 있으므로 실제 혜택의 근거가 될 수 없습니다.

실제 서비스 단계에서는 각 기관과 인증 방식 및 제공 가능한 최소 회원 정보를 합의한 후,
기관 포털의 인증 서버로 이동해 인증하고 앱 서버가 인증 결과를 검증해야 합니다.
앱 서버는 기관별 사용자 식별자와 미션 완료를 검증하여 중복 없는 마일리지 거래 내역을 저장하고,
도서관 직원의 승인 절차로 혜택 교환을 처리해야 합니다. 학교 비밀번호를 이 정적 웹앱에서 직접 받지 않습니다.

## 실행
GitHub Pages를 켜면 휴대폰에서 주소로 바로 열 수 있습니다. 앱 화면은 `index.html`에 있고,
홈 화면 설치를 위한 `manifest.webmanifest`, 아이콘, `sw.js`가 함께 필요합니다.

처음 열면 이용 안내가 시작됩니다. 강조된 버튼을 직접 눌러 난이도 선택, 오늘 연습,
미션 확인, 가게 고르기, 도움말을 익힐 수 있습니다. 안내는 언제든 그만둘 수 있고,
로비의 **막힐 때 → 이용 안내 다시 시작**에서 다시 열 수 있습니다. 안내 완료 여부는
현재 브라우저에만 저장됩니다.
각 연습에 들어가면 이번 미션이 화면 중앙 팝업으로 한 번 나타납니다. **연습 시작하기**를
누르면 팝업이 닫히고, 이후에는 접힌 **미션 다시 보기** 버튼으로 내용을 펼치거나 다시
접을 수 있습니다. 미션 때문에 연습 화면의 높이는 줄어들지 않습니다.

## 휴대폰에 앱처럼 추가하기

- 안드로이드 Chrome: 공개 HTTPS 사이트 열기 → 브라우저 메뉴 → **앱 설치** 또는 **홈 화면에 추가**.
- 아이폰 Safari: 공개 HTTPS 사이트 열기 → **공유** → **홈 화면에 추가** → **웹 앱으로 열기** 옵션이 보이면 켜기.
- 설치 후 아이콘에서 앱처럼 열립니다. 앱스토어/플레이스토어에 등록된 네이티브 앱은 아닙니다.
- 로컬 `file://` 미리보기에서는 설치할 수 없습니다. GitHub Pages 주소에서 추가해야 합니다.
- 기본 연습 화면은 오프라인에서도 열 수 있습니다. 주변 지도·택시 지도와 외부 글꼴은 인터넷이 필요합니다.

## 모바일 택시 연습

- 가게 고르기에서 **모바일 택시**를 열면 택시 앱 형태의 홈 화면이 나옵니다. **어디로 갈까요?** 또는 **택시**를 누르면 탈 곳을 고르는 지도로 이동합니다.
- **현재 위치 찾기**를 누르면 기기의 위치 권한을 요청합니다. 위치를 찾지 못해도 지도를 움직여 수동으로 탑승 지점을 지정할 수 있습니다.
- 지도 가운데 택시 표시로 탈 곳을 세밀하게 맞춘 뒤, 목적지도 지도를 움직여 정합니다. 지점 이름은 선택 사항입니다.
- 차량 종류와 결제 수단을 고르면 예상 요금과 함께 연습용 호출이 시작되고, 차량이 탑승 위치로 다가오는 애니메이션을 볼 수 있습니다.
- 택시 실습 지도는 네이버 지도 JavaScript API를 우선 사용합니다. 화면을 배치한 뒤 지도 크기를 다시 계산합니다. 네이버 지도 인증·연결에 실패하거나 지도 타일이 8초 안에 표시되지 않으면 OpenStreetMap 기반 기본 지도로 전환합니다. GPS 좌표는 기기 브라우저에서 받아 지도 위에 표시하며, 브라우저 위치 권한이 필요합니다.
- `file://` 미리보기에서는 네이버 지도 인증이 제한될 수 있어 기본 지도로 바로 전환합니다. 기본 지도 타일도 불러오지 못하면 이동·위치 선택을 연습할 수 있는 도식 지도를 표시합니다. 도식 지도는 실제 도로 정보가 아닙니다. 네이버 지도와 GPS 동작은 등록된 도메인의 공개 HTTPS 주소에서 확인하세요.
- 지도에서 그린 직선과 예상 요금, 차량 이동은 실제 길찾기·요금·배차 결과가 아닙니다. 앱은 위치 좌표와 결제 수단을 저장하지 않지만, 지도 요청은 지도 제공자에게 전달됩니다.

## 생활 서비스·사기 예방 연습

- **병원 예약, 보험 청구, 온라인 쇼핑, 쇼핑 사기, 스미싱 문자, 가족 사칭 메신저, 무인민원 발급**을 가게 고르기 또는 상단 메뉴에서 선택할 수 있습니다. 각 주제에 2개씩 총 14개 미션이 있습니다.
- 예약·청구·쇼핑·민원 발급은 가상 화면에서 단계별 선택과 마지막 확인을 연습합니다. 사기·사칭 미션은 의심 신호를 찾고 안전한 행동을 고릅니다. 잘못 고르면 이유를 보여주고 같은 단계에서 다시 선택할 수 있습니다.
- 실제 주민등록번호·신분증·영수증·카드번호·비밀번호를 입력하거나 파일을 올리는 기능은 없습니다. 외부 링크를 열거나 실제 기관에 데이터를 보내지 않습니다. 각 기관의 실제 화면과 절차는 다를 수 있습니다.
- 스미싱 미션은 [KISA 보호나라의 예방 안내](https://www.boho.or.kr/kr/bbs/view.do?bbsId=B0000030&menuNo=205027&nttId=71280), 가족 사칭 미션은 [경찰청의 메신저 피싱 예방 안내](https://www.police.go.kr/user/bbs/BD_selectBbs.do?q_bbsCode=1007&q_bbscttSn=20211230162159657)를 참고했습니다.

## 도서관·지도 연동 범위

- 이름을 기기 안에 따로 저장하는 기능과 기관 로그인 시연 기능은 별개입니다. 기존
  `코스모스 대학 도서관` 이름 선택은 화면 예시이며 포털 인증이나 마일리지와 연결되지 않습니다.
- 지도는 네이버 지도 JavaScript API로 표시합니다. 네이버 지도 로드나 인증에 실패하면
  OpenStreetMap 지도로 전환합니다. 네이버 클라우드 Maps Application에 **Dynamic Map**을
  선택하고 Web 서비스 URL로 `http://snowater121.github.io`를 등록해야 합니다.
  웹 코드에는 Client ID만 사용하며 Client Secret을 넣지 않습니다.
- 사용자가 **내 주변 찾기**를 누르고 위치 권한을 허용할 때만 주변 식당(패스트푸드 포함)과 은행을
  OpenStreetMap Overpass에서 조회합니다. 지도와 목록에서 전체·식당·은행을 골라 볼 수 있습니다.
  지도 마커에 마우스를 올리거나 휴대폰에서 누르면 장소 이름이 표시됩니다.
  목록에서 장소를 누르면 네이버 지도 웹에서 이름으로 검색합니다. 두 서비스의 장소 정보가
  다를 수 있으므로 네이버 검색 결과에서 위치를 확인해야 합니다.
  위치와 검색 결과는 저장하지 않습니다. 지도에 등록된 곳은
  실습 참여가 확인된 곳이 아닙니다. 협약 가게를 확실히 표시하려면 도서관이 제공하는
  참여 가게 명단(상호·주소·위치·실습 가능 여부)을 별도로 연동해야 합니다.
