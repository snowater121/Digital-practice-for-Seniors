# 디지털 연습소

한성대 「프로그램 기획과 평가」 AI 다리 조 — 공공도서관 고령층 디지털 교육 프로그램용 연습 앱입니다.

- 카페·패스트푸드·분식 키오스크, 테이블 오더, 모바일 뱅킹, 기차 예매 연습 (미션 31개)
- 기초반(12주·24회차) / 심화반(25주·75회차)에 맞춘 오늘의 연습 3가지, 출석부
- 막힐 때 안내, 낯선 말 풀이, 노션에 붙여넣는 연습 기록

## 주의
화면에 나오는 가게·은행·철도 이름은 연습용으로 지어낸 것이며, 실제로 주문·결제·송금이 일어나지 않습니다.
연습 기록은 사용하는 기기의 브라우저 안에만 저장됩니다.

## 실행
GitHub Pages를 켜면 휴대폰에서 주소로 바로 열 수 있습니다. 앱 화면은 `index.html`에 있고,
홈 화면 설치를 위한 `manifest.webmanifest`, 아이콘, `sw.js`가 함께 필요합니다.

## 휴대폰에 앱처럼 추가하기

- 안드로이드 Chrome: 사이트 열기 → 브라우저 메뉴 → **앱 설치** 또는 **홈 화면에 추가**.
- 아이폰 Safari: 사이트 열기 → **공유** → **홈 화면에 추가**.
- 설치 후 아이콘에서 앱처럼 열립니다. 앱스토어/플레이스토어에 등록된 네이티브 앱은 아닙니다.
- 연습 화면은 오프라인에서도 열 수 있습니다. 지도 검색과 외부 글꼴은 인터넷이 필요합니다.

## 도서관·지도 연동 범위

- 도서관 이름 표시는 기기에 저장된 사용자 프로필에 붙는 **선택형 표시**입니다. 현재의
  `코스모스 대학 도서관`은 화면 예시이며, 도서관 계정 인증이나 기록 서버 전송은 하지 않습니다.
  실제 로그인 연동에는 해당 기관의 인증 방식·API·동의 절차가 필요합니다. 기관을 고르지
  않아도 모든 연습과 출석 기능을 이용할 수 있습니다.
- 지도는 사용자가 **내 주변 찾기**를 누르고 위치 권한을 허용할 때만 주변 카페·음식점을
  OpenStreetMap에서 조회합니다. 위치와 검색 결과는 저장하지 않습니다. 지도에 등록된 곳은
  실습 참여가 확인된 곳이 아닙니다. 협약 가게를 확실히 표시하려면 도서관이 제공하는
  참여 가게 명단(상호·주소·위치·실습 가능 여부)을 별도로 연동해야 합니다.
